# Drupal Module: PDF Alt-Text Generator

This module integrates the **PDF Alt-Text Generator** into **Drupal 10 & 11**. It automatically extracts images and surrounding context from PDF media entities and provides accessible alt-texts generated by a Vision LLM (such as Qwen3.8-27B, Qwen2.5-VL, or Gemma-4) in compliance with **WCAG 2.1 (Success Criterion 1.1.1)** and **PDF/UA-1 (ISO 14289-1)**.

*(For Dutch documentation, see [README_NL.md](file:///home/rnh/projects/pdf-alt-text/drupal/pdf_alt_text/README_NL.md))*

---

## Features

1. **Editorial Review UI on Media Entities**:
   - Adds an **"Alt-Text"** tab to PDF Media entities (`/media/{id}/pdf-alt-text`).
   - Inspects the document for existing images, dimensions, and existing tags.
   - Generates AI draft alt-texts with surrounding context for editorial review.
   - Saves approved alt-texts directly into the PDF as a standard-compliant PDF/UA logical structure tree (`/StructTreeRoot`, marked content streams `/MCID`, `/ParentTree`).
2. **Revision Management**:
   - Optionally creates a new media revision upon tagging to keep the original untagged document intact.
3. **Queue Worker & Bulk Actions**:
   - Includes a `QueueWorker` (`pdf_alt_text_processor`) and Action plugin to enqueue multiple PDF documents from the Media overview (`/admin/content/media`).
4. **Dual Processing Architecture**:
   - **CLI Mode**: Direct local execution via `python3 -m pdf_alt_text` on the server host.
   - **API Mode**: Connects via HTTP REST to a Node.js (`server.js`) or FastAPI microservice.
5. **Full Internationalisation (i18n)**:
   - Written with standard English source strings and includes a complete Dutch translation file (`translations/nl.po`).

## Requirements

- Drupal 10.x or 11.x
- PHP 8.1+ with shell execution permissions (for CLI mode) or Guzzle HTTP (for API mode)
- Python 3.9+ with the `pdf-alt-text` package installed:
  ```bash
  pip install -e /path/to/pdf-alt-text
  ```

---

## Installation

1. Copy the module directory into your Drupal installation:
   ```bash
   cp -r drupal/pdf_alt_text /path/to/drupal/web/modules/custom/
   ```
2. Enable the module using Drush or the Drupal admin interface:
   ```bash
   drush pm:install pdf_alt_text
   ```

---

## Configuration

Navigate to:
**Admin > Configuration > Media > PDF Alt-Text Generator** (`/admin/config/media/pdf-alt-text`)

1. **Processing Mode**:
   - `CLI`: Uses the local Python binary/package.
   - `API`: Connects to an external REST microservice (default `http://localhost:3000`).
2. **Vision LLM Endpoint**:
   - OpenAI-compatible endpoint URL (e.g. `http://localhost:8080/v1` for llama-server / llama-router, or `http://localhost:11434/v1` for Ollama).
3. **Target Language**:
   - Select default language for generated alt-texts (`nl`, `en`, `de`, `fr`).
4. **Minimum Image Dimension**:
   - Threshold in pt/pixels (default `50`) to ignore small decorative spacers and icons.

## Usage

### 1. Manual Editorial Review per Media Item
1. Go to **Content > Media** (`/admin/content/media`).
2. Select a PDF media item and click the **"Alt-Text"** tab.
3. Click **"Generate Alt-Texts via Vision AI"**.
4. Review, adjust text, or flag images as decorative.
5. Click **"Apply & Tag PDF (PDF/UA)"**.

### 2. Bulk Background Processing via Queue
Select multiple items in the media table, choose **"Generate PDF Alt-Texts (Background Queue)"**, and run the worker:
```bash
drush queue:run pdf_alt_text_processor
```

## DDEV Integration

When developing with **DDEV**, add Python dependencies to `.ddev/web-build/Dockerfile`:

```dockerfile
RUN apt-get update && apt-get install -y python3-pip python3-venv
RUN python3 -m venv /opt/pdf-venv && \
    /opt/pdf-venv/bin/pip install --upgrade pip && \
    /opt/pdf-venv/bin/pip install pymupdf pillow httpx
```

Then configure the Python executable path in the Drupal settings form:
`/opt/pdf-venv/bin/python3`
